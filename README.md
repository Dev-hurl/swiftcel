
# SwiftCel


Swiftcel is a parcel delivery app

---

## ✨ Features

- 🎯 **Onboarding Flow** — 4-screen PageView onboarding with dot indicator
- 🔐 **Authentication** — Email/password signup & login, Google Sign-In
- 🔔 **Custom Toast Notifications** — Stacked animated toast system
- 🌙 **Light & Dark Theme** — System-aware theme switching
- ⚙️ **Settings Screen** — Profile, notifications, support, and account management
- 📁 **Camera** — Image capture and gallery integration
